# 💰 알바 머니 미터

시급과 근무 시간표를 넣으면, 일하는 동안 번 돈이 1초마다 올라가는 웹페이지예요.

## 기능
- 근무 시간에만 초 단위로 올라가는 실시간 카운터 (오늘 / 이번 주 / 이번 달 / 전체)
- 요일별 근무 시간표 (하루에 여러 칸 가능 → 휴게시간 빼기)
- 날짜별 휴무 · 시간 변경 기록
- 월급날 D-day와 이번 월급 예상 금액
- 돼지 저금통: 목표 금액 또는 한도 시간 기준으로 차오름
- 레벨업, 업적 배지, 동전 이펙트, 효과음
- 치킨 · 커피 · 국밥 · 삼각김밥 개수로 환산

## 사용법
`index.html`을 브라우저로 열면 바로 돼요. 설치나 서버가 필요 없어요.
기록은 각자 브라우저(localStorage)에만 저장돼요.

## 배포
GitHub 저장소 Settings → Pages → Branch를 `main` / `/ (root)`로 저장하면
`https://<아이디>.github.io/<저장소이름>/` 주소로 공유할 수 있어요.
